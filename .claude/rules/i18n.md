# Introduction

This application is designed to support multiple languages and cultures, ensuring that users from different regions can easily understand and navigate the interface.
We have Vietnamese and English translations for this application, and we will add more languages in the future.
For each app package, we will have different rules

## Api app

Read .github/instructions/api/response.instructions.md to know how to response with i18n

## App app (main application)

We use i18next for internationalization. You define key at
`apps/app/src/i18n/translations/{region}.json` and use it in your code like this:

```javascript
import { useTranslation } from "react-i18next";

const MyComponent = () => {
  const { t } = useTranslation();

  return (
    <div>
      <h1>{t("welcome_message")}</h1>
    </div>
  );
};
```

### Rules

- Always reuse existing translations if possible
- Actions, General - Always use the translation key as the message text
- Use english term if other language is not possible or feel crancky (e.g skills, chatbot, agents, ...)
