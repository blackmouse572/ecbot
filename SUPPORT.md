# Support

## Self-hosting

Self-hosted Ecbot is **community-supported**. There is no SLA, no guaranteed response, and no private support channel.

Ask in [GitHub Discussions](../../discussions). Before opening an issue, please reproduce it on the stack described in the README — a report we cannot reproduce there is very unlikely to get fixed.

Two categories we will close without investigating, because they are configuration rather than defects:

- Platform connections failing because you have not registered and had approved your own app on that platform (Meta, Zalo, TikTok Shop, Shopee). See the README.
- LLM errors from your own provider account — quota, billing, rate limits, model availability.

## Bug reports

Open an issue with: what you expected, what happened, how to reproduce, and the versions involved. Logs help; secrets do not — redact them.

## Security

Do not report vulnerabilities here. See [SECURITY.md](./SECURITY.md).

## Ecbot Cloud

Customers of Ecbot Cloud have a separate support channel through their account.
