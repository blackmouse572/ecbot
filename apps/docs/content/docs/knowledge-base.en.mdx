description: Add files, web pages and notes to the knowledge base so your agent answers from your own prices, policies and product details.
faq:
  - q: Which file types can I upload?
    a: PDF, Word (DOCX), plain text, HTML and Markdown files. For a web page, add its public URL. For short facts, add a text note.
  - q: Why does my item still say Draft?
    a: An item is only used after it is processed. Open the item's menu and choose Process, then wait until the status shows Completed.
  - q: Do customers see my file names?
    a: No. Customers get the answer only. Source references show in your own test chat so you can check where an answer came from.
---

The knowledge base is where you put the documents your agent answers from: price lists, product sheets, return policies and FAQs. Each item is processed once, then linked to one or more agents. For every question, the agent looks up the relevant part of your documents, so it quotes your facts instead of guessing.

## Add an item

Open **Knowledge Base** under **Agents** in the sidebar.

<Screenshot name="knowledge-base" alt="The knowledge base list with processed and draft items">
  <Mark id="create">**Create** adds a new item.</Mark>
  <Mark id="status">**Status** shows whether an item is ready. Only **Completed** items are used.</Mark>
  <Mark id="draft">A **Draft** item is not used yet. Open its menu (**...**) and choose **Process**.</Mark>

Choose what kind of item to add:

<Screenshot name="knowledge-base-create" alt="The create item form with File, URL and Text options">
  <Mark id="type">**File** uploads a document, **URL** reads a web page, **Text** is a note you type.</Mark>
  <Mark id="formats">Files can be PDF, DOCX, TXT, HTML or MD.</Mark>
</Screenshot>

A URL must be publicly reachable. Pages behind a login or on your own computer cannot be read.

## Link items to an agent

Open the agent's page, go to the **Knowledge Base** section and choose **Add**. Pick the items this agent should use. An agent only answers from the items linked to it.

## Keep it current

When a price or policy changes, edit the item and process it again. Short facts that change often (opening hours, delivery fee) can live in the agent's business facts instead, see [Agent builder](/docs/agent-builder).
