faq:
  - q: What happens when the quota is used up?
    a: Agents stop generating replies and send their fallback message instead, until the quota renews or extra credit is added.
  - q: What counts as usage?
    a: AI tokens used for replies on channels, follow-ups, the website widget and the test chat all count toward the quota.
  - q: Is the Usage page in the self-hosted version?
    a: No. Usage metering and plans are part of the hosted Ecbot at ecbot.dev. A self-hosted install does not limit or record AI usage.

The **Usage** page shows how much AI your agents used in the current plan period and where it went. Every reply your agents write uses AI tokens, and your plan includes a quota that renews each period. Check this page to see which agent or channel uses the most, and set an alert so you hear about it before the quota runs out.

Use **Export CSV** to download the numbers for the selected range.

## When the quota runs out

Agents keep answering, but with their fallback message instead of an AI reply, until the quota renews or extra credit is added. Set the fallback message in the agent's **Behavior** settings (see [Agents](/docs/agents)) so customers know someone will get back to them.
