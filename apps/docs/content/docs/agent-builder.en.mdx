The agent builder creates an agent from a short description of your business. It asks one question at a time about your shop, how the agent should talk and when it should pass the chat to you, and fills in the answers it can work out from your description. A test chat sits beside the questions so you can try the agent before you turn it on.

## What the builder asks

- **About your business**: the type of business, its name, the agent's name, the greeting and what makes your shop different.
- **Voice**: words that describe your brand and how formal the agent should sound.
- **Business facts**: shipping fees and times, delivery, payment methods, returns and warranty. Short facts belong here; long documents belong in the [knowledge base](/docs/knowledge-base).
- **How it works**: the details the agent collects from a customer who is ready to buy, and when it hands the chat to you. See [Customers and handoff](/docs/customers-and-handoff).
- **Rules**: things the agent must never do, and what it does when it is unsure.
- **Conversation style**: reply length, emoji, follow-up questions and what to do outside opening hours.

When you reach the end, try a few questions in the test chat, then choose **Activate agent**.

## After the agent is created

The agent's page holds everything the agent uses. Link documents, add tools and keep testing from one place:

  <Mark id="knowledge">**Knowledge Base**: the documents this agent answers from. **Add** links more.</Mark>
  <Mark id="tools">**Tools**: the systems this agent can use, such as your order API.</Mark>

Write facts the way you would tell a new staff member. If your shop has no opening hours (for example, online only), say so, so the agent does not invent them.
