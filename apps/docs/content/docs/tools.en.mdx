faq:
  - q: What is the difference between a tool and a skill?
    a: A tool does something, such as looking up stock in your system. A skill is text that explains how to handle a kind of request, for example the steps for a late delivery. Skills can tell the agent which tools to use.
  - q: Which marketplace apps can I connect?
    a: The marketplace lists hosted apps such as Gmail, Google Sheets and KiotViet that connect with one sign-in. Each app shows the actions it offers, and you choose which ones the agent may use.
  - q: Is it safe to give the agent access to my accounts?
    a: Turn on only the actions the agent needs to serve customers. A customer can ask the agent anything, so avoid enabling actions that read private files or change data unrelated to the agent's job.

Tools connect your agent to other systems so it can do more than answer questions. With a tool, the agent can check stock, look up an order, create an order or read a Google Sheet. Skills are the other half: short written guides that tell the agent how to handle one kind of request, step by step.

## Create a tool

Open **Tools** under **Agents** in the sidebar and choose **Create**:

<Screenshot name="tool-types" alt="The tool type picker with HTTP Tool, Custom MCP and Marketplace">
  <Mark id="http">**HTTP Tool** calls an endpoint on your own server. Set the URL, method and authentication, then use the test to check the response.</Mark>
  <Mark id="mcp">**Custom MCP** connects to a Model Context Protocol server. Ecbot discovers its actions, and you turn on the ones you want.</Mark>
  <Mark id="marketplace">**Marketplace** installs a ready-made app, such as Google Sheets, with one sign-in.</Mark>
</Screenshot>

After you create a tool, open the agent's page and add it in the **Tools** section. Each agent uses only the tools added to it.

## Skills

A skill is a named set of instructions, for example "Handle a late delivery: apologize, ask for the order code, check the status, offer a solution." The agent reads a skill's description and loads the full text only when a conversation needs it.

Open **Skills** to write your own with **Create**, or copy a ready-made one with **Browse templates**, then attach it to the agent. Write the steps the way you would train a new staff member.
