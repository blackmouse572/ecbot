---
title: Set up your shop
description: Create an Ecbot account and workspace, build your first agent with the agent builder, and test it before any customer sees it.
faq:
  - q: How long does setup take?
    a: Most shops finish the first agent in 15 to 20 minutes. The agent builder asks one question at a time and fills in what it can from your description.
  - q: Can I test the agent before customers use it?
    a: Yes. Every agent has a test chat on its page. Messages you send there do not reach any channel, so you can try prices, policies and tricky questions safely.
  - q: Can my staff use the same workspace?
    a: Yes. Invite them from the workspace settings under Team. Each person signs in with their own account.
---

To start with Ecbot, create an account, make a workspace for your shop, and build an agent with the agent builder. The whole flow takes about 15 minutes, and you can test the agent in a private chat before connecting it to Messenger, Zalo, Telegram, WhatsApp or your website.

<Steps>
<Step>

### Create your account

Sign up with your email and a password, then enter the 6-digit code we email you.

</Step>
<Step>

### Create a workspace

Give the workspace your shop's name. Each shop or client gets its own workspace, with its own agents, documents and team.

</Step>
<Step>

### Build your first agent

Open **Agents** in the sidebar and create a new agent. The agent builder opens:

<Screenshot name="builder-start" alt="The agent builder start screen with a description box and business templates">
  <Mark id="describe">Describe your business in a sentence or two. The builder fills in the answers it can.</Mark>
  <Mark id="templates">Or start from a template for your type of business.</Mark>
</Screenshot>

See [Agent builder](/docs/agents) for what each question means.

</Step>
<Step>

### Add what the agent should know

Add your price list, policies and FAQ to the [knowledge base](/docs/agents/knowledge-base) and link them to the agent.

</Step>
<Step>

### Test, then connect a channel

Ask the test chat the questions your customers ask most. When the answers look right, [connect a channel](/docs/channels).

</Step>
</Steps>
