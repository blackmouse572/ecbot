Before customers write in, check that your agent answers the way your best staff member would. Try the questions below in the test chat, fix anything that is wrong, then send a real message on your channel to confirm it is live. This page assumes you have [set up your first agent](/docs/getting-started/setup).

## Try these in the test chat

Open your agent and use the **Test Chat**. Nothing you send there reaches a customer. Ask, in your customers' words:

- **A price**: "How much is the large size?" The answer should match your price list.
- **A policy**: "Can I return this if it doesn't fit?" It should give your real return rule.
- **Opening hours or address**: "Are you open on Sunday?"
- **Something you don't sell**: it should say so or offer something close, not invent a product.
- **A question it can't know**: it should follow your rule for unsure cases, for example say it will check.
- **A request for a person**: "Can I talk to someone?" It should hand the chat to your staff.
- **An unhappy message**: "My order is late and nobody answers me." It should stay calm and hand over if that is your rule.
- **Your language mix**: if customers write without accents or mix Vietnamese and English, test that too.

## Fix a wrong answer

| What happened                       | What to change                                                                                     |
| ----------------------------------- | -------------------------------------------------------------------------------------------------- |
| A price or fact is wrong or missing | Add or update it in the [knowledge base](/docs/agents/knowledge-base), or in the builder's answers |
| The tone is off                     | Change the voice and formality answers in the [agent builder](/docs/agents)                        |
| It promised something you don't do  | Add it to the rules about what the agent must never do                                             |
| It didn't hand over when it should  | Check the handoff answers and **Handoff Settings** on the agent's page                             |

Ask the same question again after each change. Changes apply to new messages.

## Go live

1. Connect the channel where most of your customers write to you. See [Channels](/docs/channels).
2. Link the agent to that channel account. A channel with no linked agent stays silent.
3. Turn the agent on with the switch at the top of its page.
4. From your own personal account, send the channel a message, for example a price question.
5. Open **Conversations** and check that your message and the agent's reply are there.

## After launch

- Read new chats in **Conversations** for the first few days. Each question the agent answered badly is a fact to add.
- Watch for chats marked **Needs you**: the agent handed them to your staff. See [Customers and conversations](/docs/customers).
- When the basics work, teach the agent a task, starting with [Capture a lead](/docs/cookbook/use-cases/capture-lead).
